# Команды автолаборатории (Telegram-бот)

Как вводить: слово команды и аргументы через пробел, например `повтор ab_batch8_auto_40k 3`. Можно с префиксом `/autolab` (`/autolab повтор ...`) и с упоминанием бота (`@бот повтор ...`). Регистр не важен. Работает только для пользователей и чатов из белого списка; остальным бот молчит.

`<имя>` — имя гипотезы латиницей (`ab_...`), его видно в `гипотезы` и в отчётах. `[...]` — необязательный аргумент. Режим цели: `accuracy` (больше очков) или `economy` (меньше токенов при тех же очках).

Команды, которые тратят только токены шлюза и локальной Qwen (они бесплатны на соревновании): `повтор`, `проверка`, `локально вкл`, запускаются сразу, смета и результат приходят одним сообщением. Команды, которые тратят деньги (запросы к Claude: `идеи`, `цикл`, `рецензия`, `автопилот вкл`, `ключ`) и необратимые (`принять`) сначала показывают оценку и кнопку «Запустить». Код подтверждения действует 10 минут, одноразовый, подтвердить может только тот, кто спросил.

## Смотреть

| Команда | Что делает |
|---|---|
| `статус` | что сейчас идёт: очередь, запущенное, автопилот |
| `очередь` | эксперименты в очереди и в работе |
| `расход` | сколько потрачено запросов и токенов |
| `гипотезы [все]` (или `список`) | гипотезы, по которым ждут вашего решения, кнопка на каждую; `все` — полный список |
| `отчёт <имя>` | отчёт файлом с кнопками решения |
| `вердикт <имя>` | вердикт коротко |
| `журнал [<блок> <тип> [N]]` (или `история`) | что пробовали: без аргументов последние записи, с блоком и типом история ячейки |
| `отложенные` | гипотезы, которые вы отложили |

## Решать по гипотезе

У каждой гипотезы кнопки: ✅ Принять, ❌ Отклонить, 🔍 Ревью, 🔁 Повтор, 🧪 Другие данные, ⏸ Отложить. Текстом то же самое:

| Команда | Что делает |
|---|---|
| `гипотеза <имя>` (или `карточка`) | карточка: состояние, режим, ячейки, результат, кнопки |
| `принять <имя>` | слить в код и запушить (после подтверждения) |
| `отклонить <имя>` | закрыть, типы задач освобождаются |
| `отложить <имя>` | отложить, типы освобождаются |
| `рецензия <имя>` | независимое мнение модели; в конце совет, на каких данных перепроверить |
| `повтор <имя> [n]` | то же на тех же данных; без `n` бот сам считает число повторов (от 2 до лимита) |
| `проверка <имя> [набор]` | то же на других данных; набор по совету рецензии, иначе бот предложит наборы под типы задач, или укажите свой |

Пока гипотеза ждёт решения, она держит свои типы задач: новые гипотезы на эти типы не ставятся.

## Дать задание

| Команда | Что делает |
|---|---|
| `идеи [n] [accuracy\|economy] [тема]` | придумать гипотезы и проверить в симуляторе, шлюз не тратится |
| `цикл [n] [accuracy\|economy] [тема]` | придумать, поставить в очередь и дождаться вердикта; без режима поровну |
| `своя <блок>/<тип> <текст>` | ваша гипотеза для ячейки, встаёт первой в очереди (можно кнопкой под ячейкой, тогда текст пишете следующим сообщением) |

Пример: `цикл 2 economy порядок задач при бюджете 30k`.

## Схема статусов (14 блоков × 4 типа задач)

| Команда | Что делает |
|---|---|
| `схема` | готовность блоков по типам задач |
| `приоритеты [accuracy\|economy]` | что стоит делать: общий рейтинг или рейтинг режима |
| `блоки` / `типы` | списки с кнопками |
| `блок <имя>` | четыре типа одного блока |
| `тип <coding\|math\|search\|data_analysis>` | блоки одного типа задач |
| `ячейка <блок> <тип>` (или `<блок>/<тип>`) | текст ячейки и md-файл |
| `привязать <имя> <блок>/<тип>` | привязать гипотезу к ячейке |

## Управлять

| Команда | Что делает |
|---|---|
| `стоп` / `продолжить` | остановить и вернуть запуски |
| `автопилот [вкл\|выкл]` | сам пополняет очередь гипотезами; без аргумента показывает состояние |
| `локально [вкл\|выкл]` | сбор данных на локальной Qwen хоста |
| `шеф [вкл\|выкл\|план\|дайджест]` | агент-шеф ведёт траекторию улучшений сам: ставит гипотезы, проверки, ревью, принимает только в ветку `auto/<имя>` (в main после вашего `принять`); `вкл` спросит подтверждение; по умолчанию dry-run |
| `стек [сбросить]`, `принять стек` | накопленные шефом гипотезы (ветка `auto/stack`): состав, общая проверка; `принять стек` сливает в main после пройденной проверки (с подтверждением) |
| `ключ` (или `проверка ключа`) | провайдер ключа Claude (OpenRouter или Anthropic), модели ролей, расход и остаток на ключе без траты; кнопка «Проверить запросом» делает один вызов (около 0,0001 $) |
| `меню` | кнопки основных действий |
| `помощь` / `команды` | этот список |
| `/id` | узнать свой Telegram id (для белого списка) |
| `ok <код>` | то же, что кнопка «Запустить» (код из сообщения с оценкой) |

## Заметки

- Обычные слова вроде `блок`, `тип`, `гипотеза` бот ловит только с латинским аргументом или без него; другой текст в группе уходит агенту.
- Критерии лаборатории (порог шума 7.69, замороженные наборы) бот не меняет.
- Принятие вливает код только в копию на хосте и пушит ключом доступа; `--force` бот не использует.
