## Реализовано
`harness/guess.py`: `HARNESS_GUESS_UNSOLVABLE=off|free|llm` (по умолчанию `off`), `HARNESS_SUBMIT_UNSOLVABLE=on` (по умолчанию: ответ пишется даже при вердикте «нерешаема»); coding → `DONE` без токенов, прочие `llm` — один короткий вызов (300 токенов).

## Измерено
`ab_guess_free_contradiction_20k` (`mixed100_dev`, 20k, 2 повтора): пропуск 202,0 против пропуск + `GUESS=free` 196,0, −6,0 [−18,5; +6,5], clarify; `ab_guess_llm_vs_free_20k_coding` (coding, 20k, 1 повтор): free 98,0 против llm 96,0, −2,0 [−6,0; 0], clarify; `ab_skip_contradiction_30k` отсеян симулятором. В лаборатории верный ответ на невыполнимую задачу = отсутствие ответа, поэтому польза угадывания не измерима. Модульные проверки.

## Чем ограничено измерение
В лаборатории «верно» для невыполнимой задачи = «нет ответа» (`baseline0`: recall/precision), то есть метрика лаборатории противоположна идее угадывания; как организаторы засчитывают ответ на нерешаемую задачу — открытый вопрос правил (SCHEME).
