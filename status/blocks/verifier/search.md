## Реализовано
Судья отключён для search по умолчанию (AUC 0,5–0,6); сигнал `agree_other` (другая модель) AUC 0,76–0,82; `search_check.py` по источнику — оффлайн.

## Измерено
Оффлайн: free 0,56, judge 0,62, other 0,79. `verify_other` search: AUC 0,76, поймано 0,57, ложных тревог 0,22; очки search 0,50 → 0,70–0,80. Но `verify_other_fresh`: search 0,90 → 0,70 (other хуже на 2 задачах из 10). Оффлайн по источнику (450 задач): AUC 0,51 [0,44–0,56]; второй путь исправляет 18, ломает 71.

## Чем ограничено измерение
Неверных 7–37; локальная модель; открытые датасеты.

## Не проверено
Любые детекторы search с AUC > 0,8 при цене ≤ 150 токенов.

## Потенциал
Самая большая яма (41% неверных на `baseline0`), но пока найденные детекторы либо слабы, либо вредят замене ответов; потенциал высокий, достоверность низкая.
