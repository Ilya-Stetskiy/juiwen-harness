## Реализовано
Конвейер coding: до 2 раундов (код → тесты → правка), детектор противоречий до первого вызова; без запасного агента ответ `DONE`-маркер.

## Измерено
`baseline0`: точность 0,987 (выполнимые 0,98), 779 токенов на задачу (1 146 на выполнимую), невыполнимые 0 токенов. `coding_pipeline_vs_hybrid`: конвейер 88,9% при 934 токенах против с агентом 91,7% при 3 053.

## Чем ограничено измерение
Открытый синтетический `codegen_fix`; видимые тесты — метка тоже по ним (скрытые тесты организаторов не проверены); на сложных наборах (`coding_late_tier`) конвейер даёт ≈81%.

## Не проверено
Скрытые тесты; другая сложность задач.

## Потенциал
На `baseline0` потолок потерь по очкам ≈0,9, роста по точности нет. Остаётся стоимость (≈1,1k токенов на задачу): снижать её имеет смысл только при бюджете 20–30k. **Насыщено на доступных данных.**

## Связи с другими блоками
`fallback` (запасной агент), `solvers/coding`, `verifier/coding` (тесты как проверка).
